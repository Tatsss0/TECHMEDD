🔍 Doctor Availability Checker

This tool checks if a doctor's availability is properly configured for the automated scheduler.


📋 How Availability is Set

Two ways to set doctor availability:

Method 1: Doctor Sets Their Own (profile.html)

Doctors log into their profile and add available dates/times

Method 2: Secretary Sets for Doctor (secretary.html)

Secretary logs in and sets availability for their assigned doctor

Both methods save in the same format:

Format: Specific Dates Array

{
  "schedule": [
    {
      "date": "2026-01-15",
      "time": "9:00 AM - 5:00 PM"
    },
    {
      "date": "2026-01-16",
      "time": "10:00 AM - 3:00 PM"
    }
  ]
}

Saved to:

  • users/doctors/doctors/{doctorId}
  • public_doctors/{doctorId}

Format 2: Weekly Schedule

{
  "schedule": {
    "workingDays": [1, 2, 3, 4, 5],
    "startHour": "09:00",
    "endHour": "17:00",
    "byDay": {
      "1": { "startHour": "09:00", "endHour": "17:00" },
      "2": { "startHour": "10:00", "endHour": "18:00" }
    }
  }
}
